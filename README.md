# Java E-Commerce Application

## Project Overview

The Java E-Commerce Application is a console-based shopping system developed using Core Java. It allows users to view available products, add products to a shopping cart, calculate the total price, and place orders.

The project demonstrates fundamental Java programming concepts and Object-Oriented Programming (OOP).

## Features

* **View Products:** Display available products with prices and stock details.
* **Add to Cart:** Select products and specify quantities.
* **Shopping Cart:** View selected products and their total prices.
* **Price Calculation:** Automatically calculate the total bill.
* **Stock Management:** Update product stock after order confirmation.
* **Order Processing:** Confirm or cancel an order.
* **Interactive Menu:** Navigate through the application using a menu-driven interface.

## How It Works

1. The application displays the available products.
2. The user selects a product using its ID.
3. The selected product is added to the shopping cart.
4. The application calculates the total bill.
5. The user enters their name and confirms the order.
6. The product stock is updated after successful order confirmation.
